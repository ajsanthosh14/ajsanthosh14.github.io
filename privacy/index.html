privacy policy

Santhosh Portfolio

Effective date: August 14, 2026

This privacy policy describes how the Santhosh Portfolio uses data obtained through the WHOOP API for a personal training dashboard displayed on this website.

Data accessed

The integration may access workout information authorized through WHOOP, including activity type, workout timing, strain, and related workout metrics needed to calculate training summaries.

How the data is used

The data is used only to generate personal training statistics and activity summaries for the portfolio owner. It is not sold, used for advertising, or shared with data brokers.

Storage and security

OAuth credentials and refresh tokens are kept outside the public website source code and are not intentionally exposed to website visitors. Only the minimum data needed to render the dashboard is published to the site.

Third-party services

This integration relies on WHOOP and GitHub Pages. Their own privacy policies and terms apply to their services.

Revoking access

WHOOP access can be revoked at any time through the user's WHOOP account settings. Revoking access stops future data retrieval by this integration.

Contact

Questions about this privacy policy can be sent to ajsanthosh12@gmail.com.
